Propriétés de mise en page des couvertures

Comment chaque propriété du fichier cover-properties.json d’un livre change sa couverture. Chaque image correspond à la couverture par défaut avec les propriétés indiquées à côté : seules celles-ci diffèrent de la couverture par défaut.

Les parties d'une couverture

Une couverture imprimée est une seule feuille : la quatrième de couverture à gauche, le dos au milieu et la première de couverture à droite. Les propriétés sont regroupées par la partie qu’elles changent : whole pour la couverture entière, back pour la quatrième, spine pour le dos et front pour la première, et settings pour les autres. Avec settings.debug-boxes, la couverture montre les zones où le texte est placé : sur la quatrième, l’encadré de marge (rouge), le texte (vert) et la zone du bas avec le logo, le prix et le code-barres (bleu) ; sur le dos et la première, les sections de l’auteur, du titre et de l’épigraphe.

Montrer les zones de la couverture

Seulement pour vérifier une mise en page : laissez-la à false sur les vraies couvertures.

{
    "settings": {
        "debug-boxes": true
    }
}

Écrire les valeurs

  • Les couleurs s’écrivent #RRGGBB, comme dans les logiciels de dessin : #547516 est un vert. Ajoutez deux chiffres pour l’opacité, #RRGGBBAA : 00 est invisible, 80 à moitié transparent, FF opaque.
  • Les longueurs ont une unité : 12pt pour les tailles de police, 10mm pour les distances. Elles sont données pour une couverture de 14 × 21 cm, et grandissent avec les couvertures plus grandes (16 × 24 cm).
  • Les images sont des noms de fichiers : les images se trouvent dans le dossier de la couverture.
  • Les polices sont des noms de familles, du dossier des polices.
  • Une propriété absente garde sa valeur par défaut : n’écrivez que ce qui change.

Arrière-plans

Chaque partie a un arrière-plan, background : whole.background, back.background, spine.background et front.background, et l’encadré de marge de la quatrième, back.margin-box, en prend un aussi. Un arrière-plan est peint en trois couches, chacune quand elle est définie : sa couleur, color, puis son dégradé, gradient, puis son image, image. Une image transparente ou un dégradé translucide laisse voir les couches du dessous. Les exemples sans l’image de la première de couverture par défaut le précisent.

Couleurs unies

La couverture entière, puis chaque partie, peinte par-dessus. Sans l’image de la première.

{
    "back": {
        "background": {
            "color": "#F4EFE1"
        },
        "margin-box": {
            "color": "#C9A227"
        }
    },
    "spine": {
        "background": {
            "color": "#2E4A62"
        }
    },
    "front": {
        "background": {
            "color": "#2E4A62"
        }
    }
}

Un dégradé

Un dégradé, gradient, va de la première couleur de ses stops, en haut, à la dernière, en bas. Sans l’image de la première.

{
    "front": {
        "background": {
            "gradient": {"stops": ["#1E3A8A", "#93C5FD"]}
        }
    }
}

Un dégradé incliné

Son angle, angle, est donné en degrés, comme en CSS : 0 va vers le haut, 90 vers la droite, 180 (par défaut) vers le bas, 270 vers la gauche.

{
    "back": {
        "background": {
            "gradient": {"angle": 45, "stops": ["#FDE68A", "#F97316"]}
        }
    }
}

Un dégradé radial

type: radial va du centre de la partie, dans la première couleur, à ses coins, dans la dernière. Sans l’image de la première.

{
    "front": {
        "background": {
            "gradient": {"type": "radial", "stops": ["#FFFFFF", "#7EA117"]}
        }
    }
}

Un dégradé translucide sur une couleur

Le dégradé passe du transparent au sombre sur la couleur : les couches s’additionnent. Sans l’image de la première.

{
    "front": {
        "background": {
            "color": "#C2410C",
            "gradient": {"stops": ["#00000000", "#000000CC"]}
        }
    }
}

Une image à cheval sur le dos

front.background.image-starts-in-spine fait commencer l’image de la première au dos ; back.background.image-expands-into-spine prolonge l’image de la quatrième sur le dos.

{
    "front": {
        "background": {
            "image": "photo.png",
            "image-starts-in-spine": true
        }
    }
}

L'encadré de marge de la quatrième

back.margin-box est une bande le long du bord gauche de la quatrième, avec une ombre à sa droite. Elle prend un arrière-plan comme les parties.

{
    "back": {
        "margin-box": {
            "gradient": {"stops": ["#7EA117", "#1F3A0B"]}
        }
    }
}

Texte : police, taille, couleur et casse

Chaque texte de la couverture a les mêmes propriétés : back.title, back.subtitle, back.volume, back.volume-title, spine.author, spine.title, front.author, front.title, front.subtitle, front.volume, front.volume-title et front.epigraph. Sa police, font, règle la famille (family), la taille (size), le style (style) et la casse (case) des lettres, et son remplissage, fill, leur couleur. Un texte rétrécit jusqu’à tenir dans sa zone : sa font.size est la plus grande taille qu’il prend.

Police, taille et couleur

font.family est une famille de polices du dossier des polices.

{
    "front": {
        "title": {
            "font": {"family": "Myriad Pro", "size": "44pt"},
            "fill": "#B45309"
        }
    }
}

Gras et italique

font.style vaut None, Bold (gras), Italic (italique) ou Bold-Italic.

{
    "front": {
        "author": {
            "font": {"style": "Bold"}
        },
        "title": {
            "font": {"style": "None"}
        }
    }
}

Majuscules

font.case vaut None, UpperCase (majuscules), TitleCase (une majuscule au début de chaque mot) ou SmallCaps (petites capitales).

{
    "front": {
        "author": {
            "font": {"case": "SmallCaps"}
        },
        "title": {
            "font": {"case": "UpperCase"}
        }
    }
}

Texte translucide

Deux chiffres de plus dans la couleur du fill rendent le texte translucide.

{
    "front": {
        "title": {
            "fill": "#54751680"
        }
    }
}

Effets de texte

Les bordures, dégradés, images et bandeaux fonctionnent sur tous les textes sauf le texte de la quatrième. Un remplissage, fill, est une couleur ou un dégradé ; une image, image, le remplace. Une bordure, border, a aussi un fill.

Une bordure

border prend un fill et une épaisseur, width, de 1.25pt par défaut.

{
    "front": {
        "title": {
            "border": {"fill": "#1F2937", "width": "1pt"}
        }
    }
}

Contour seul

Un fill entièrement transparent (00) avec une bordure laisse le contour des lettres.

{
    "front": {
        "title": {
            "fill": "#FFFFFF00",
            "border": {"fill": "#547516", "width": "1.5pt"}
        }
    }
}

Un dégradé

Un fill en dégradé liste ses couleurs dans stops, de la première à la dernière, avec un angle en degrés, comme un dégradé d’arrière-plan : ici de la gauche (90) vers la droite.

{
    "front": {
        "title": {
            "fill": {"angle": 90, "stops": ["#C0392B", "#2E86C1"]}
        }
    }
}

Un dégradé à plusieurs couleurs

D’autres stops ajoutent des couleurs entre la première et la dernière. Une position, de 0 à 100, peut suivre une couleur : #F1C40F 50 ; les couleurs sans position sont réparties régulièrement.

{
    "front": {
        "title": {
            "fill": {"stops": ["#C0392B", "#F1C40F 50", "#2E86C1"]}
        }
    }
}

Un dégradé radial

type: radial va du centre du texte vers ses coins.

{
    "front": {
        "title": {
            "fill": {"type": "radial", "stops": ["#F1C40F", "#B91C1C"]}
        }
    }
}

Un dégradé de bordure

Un border.fill en dégradé prend les mêmes valeurs qu’un dégradé de texte.

{
    "front": {
        "title": {
            "fill": "#FFFFFF",
            "border": {"fill": {"angle": 90, "stops": ["#7C3AED", "#DB2777"]}, "width": "2pt"}
        }
    }
}

Une image dans le texte

image remplit les lettres avec une image du dossier de la couverture.

{
    "front": {
        "title": {
            "image": "text-texture.png"
        }
    }
}

Un bandeau d'arrière-plan

band dessine un bandeau sous le texte : sa couleur, color, sa marge, padding (1mm par défaut), et son arrondi, radius. Sans l’image de la première.

{
    "front": {
        "background": {
            "color": "#2E4A62"
        },
        "author": {
            "band": {"color": "#FFFFFFCC", "padding": "2mm", "radius": "2mm"}
        }
    }
}

Un seul dégradé pour le bloc du titre

Avec extent: block, le titre partage son dégradé, son image et son bandeau avec son sous-titre et son volume.

{
    "front": {
        "title": {
            "fill": {"stops": ["#C0392B", "#2E86C1"]},
            "extent": "block"
        }
    }
}

Rotation

rotation tourne l’auteur, le titre ou l’épigraphe dans le sens des aiguilles d’une montre, en degrés : -8 l’incline vers le haut.

{
    "front": {
        "title": {
            "rotation": -8
        }
    }
}

Sous-titre, volume et titre du volume

Le sous-titre, le volume et le titre du volume suivent le titre, en dessous. Ils prennent la police (font), le remplissage (fill), l’image (image) et la bordure (border) du titre, sauf s’ils définissent les leurs ; leur taille est plus petite que celle du titre, sauf s’ils la définissent. hidden les masque : back.hidden, spine.hidden et front.hidden prennent subtitle, volume et volume-title, à true pour masquer.

Afficher le volume

La première de couverture masque le volume par défaut : front.hidden.volume: false l’affiche.

{
    "front": {
        "hidden": {
            "volume": false
        },
        "subtitle": {
            "fill": "#B45309"
        },
        "volume": {
            "font": {"size": "20pt"}
        }
    }
}

Quatrième de couverture

La quatrième montre le titre, le texte de présentation du livre et sa vignette, puis l’éditeur, le prix et le code-barres en bas.

Le titre sur la quatrième

back.title.inline l’écrit sur une ligne, back.hidden.title le retire.

{
    "back": {
        "title": {
            "font": {"size": "24pt", "case": "UpperCase"},
            "fill": "#B45309"
        }
    }
}

Le texte de la quatrième

back.content règle sa police, font, et sa couleur, fill. Le texte rétrécit à partir de cette taille jusqu’à tenir.

{
    "back": {
        "content": {
            "font": {"size": "11pt"},
            "fill": "#1F3A0B"
        }
    }
}

La vignette

back.thumbnail est une petite image dans le texte, encadrée avec une ombre. top-line-skip la descend d’un nombre de lignes de texte ; width et hoffset (jusqu’où elle entre dans l’encadré de marge) règlent sa taille et sa place.

{
    "back": {
        "thumbnail": {
            "top-line-skip": 4,
            "width": "35mm",
            "hoffset": "20mm"
        }
    }
}

Une vignette sans cadre

Avec back.thumbnail.wrap: contour, le texte suit le contour d’une image à fond transparent.

{
    "back": {
        "thumbnail": {
            "image": "back-thumbnail.png",
            "wrap": "contour"
        }
    }
}

Dos

Le dos montre l’auteur en haut, le titre au milieu et le logo de l’éditeur en bas. spine.hidden.title masque le titre.

Texte du dos

Le volume suit le titre sur le dos.

{
    "spine": {
        "background": {
            "color": "#1F2937"
        },
        "title": {
            "font": {"case": "UpperCase"},
            "fill": "#FDE68A"
        }
    }
}

Première de couverture

La première empile trois sections : par défaut l’auteur (en haut), le titre (au milieu) et l’épigraphe (en bas). Un cadre place un texte à des coordonnées précises à la place.

Une section de titre plus grande

front.section-layout: big-title donne au titre les trois quarts de la hauteur, à l’épigraphe un quart.

{
    "front": {
        "section-layout": "big-title"
    },
    "settings": {
        "debug-boxes": true
    }
}

Descendre l'auteur

section choisit la section de front.author, front.title ou front.epigraph, avec son alignement. Deux textes ne peuvent pas partager une section.

{
    "front": {
        "author": {
            "section": {"name": "lower", "valign": "bottom", "halign": "center"}
        },
        "title": {
            "section": {"name": "upper", "valign": "top", "halign": "center"}
        }
    }
}

Un texte à des coordonnées précises

box place le texte dans un rectangle mesuré depuis le coin supérieur gauche de la première, sur une couverture de 14 × 21 cm.

{
    "front": {
        "title": {
            "box": {"top": "120mm", "left": "15mm", "bottom": "170mm", "right": "90mm", "valign": "center", "halign": "left"}
        }
    },
    "settings": {
        "debug-boxes": true
    }
}

L'épigraphe

Une citation sous le titre, affichée avec front.hidden.epigraph: false. Sans l’image de la première.

{
    "front": {
        "background": {
            "color": "#F4EFE1"
        },
        "hidden": {
            "epigraph": false
        },
        "epigraph": {
            "font": {"family": "Myriad Pro", "size": "13pt", "style": "Italic"},
            "fill": "#547516"
        }
    }
}

Polices

Chaque famille de polices utilisée par une couverture a un dossier du même nom dans le dossier Nextcloud Book covers/_fonts, par exemple Book covers/_fonts/Myriad Pro. Choisissez une famille dans ce dossier, et écrivez le nom exact de son dossier dans les propriétés font.family. Une famille sans dossier arrête la génération de la couverture.

Ajouter une police

  1. Créez un dossier au nom de la famille dans Book covers/_fonts.
  2. Mettez-y les fichiers de la police : .ttf ou .otf, un par style. Le style normal est obligatoire ; le gras, l’italique et le gras italique servent aux textes Bold, Italic et Bold-Italic.
  3. Ajoutez un fichier fontconfig.json, qui donne le nom de la famille et le fichier de chaque style :
{
    "family": "Myriad Pro",
    "files": {
        "Regular": "MyriadPro-Regular.ttf",
        "Bold": "MyriadPro-Bold.ttf",
        "Italic": "MyriadPro-Italic.ttf",
        "BoldItalic": "MyriadPro-BoldItalic.ttf"
    }
}

Langues

Une seule couverture sert à toutes les langues d’un livre. settings.languages change quelques propriétés pour une langue, comme une taille de police ou un cadre ; settings.font-substitutions remplace les polices qui n’ont pas les lettres d’une langue, comme les lettres russes dans une police faite pour le français. Une police de remplacement a aussi besoin de son dossier dans _fonts, sauf si elle est installée avec docpross.

{
    "front": {
        "title": {
            "font": {"size": "60pt"}
        }
    },
    "settings": {
        "languages": {
            "am": {
                "front": {
                    "title": {
                        "font": {"size": "40pt"}
                    }
                }
            }
        },
        "font-substitutions": {
            "ru": {
                "*": "Noto Sans",
                "Abadi MT": "Noto Sans Light"
            }
        }
    }
}
