Cover layout properties

The parts of a cover

A print cover is one sheet: the back on the left, the spine in the middle and the front on the right. The properties are grouped by the part they change: whole, back, spine and front, and settings for the others. With settings.debug-boxes, the cover shows the areas the text is placed in: on the back, the margin box (red), the text (green) and the bottom area with the logo, price and barcode (blue); on the spine and the front, the author, title and epigraph sections.

Show the areas of the cover

Only for checking a layout: leave it false on real covers.

{
    "settings": {
        "debug-boxes": true
    }
}

How to write values

  • Colors are written #RRGGBB, as in design tools: #547516 is a green. Add two digits for the opacity, #RRGGBBAA: 00 is invisible, 80 half transparent, FF opaque.
  • Lengths take a unit: 12pt for font sizes, 10mm for distances. They are given for a 14 × 21 cm cover, and grow with larger covers (16 × 24 cm).
  • Images are file names: the images sit in the cover’s folder.
  • Fonts are family names, from the fonts folder.
  • A property left out keeps its default: write only what changes.

Backgrounds

Each part has a background: whole.background, back.background, spine.background and front.background, and the margin box of the back, back.margin-box, takes one too. A background is painted in three layers, each when it is set: its color, then its gradient, then its image. A transparent image or a translucent gradient lets the layers below show through. The examples without the front image of the default cover say so.

Plain colors

The whole cover, then each part, painted over it. Without the front image.

{
    "back": {
        "background": {
            "color": "#F4EFE1"
        },
        "margin-box": {
            "color": "#C9A227"
        }
    },
    "spine": {
        "background": {
            "color": "#2E4A62"
        }
    },
    "front": {
        "background": {
            "color": "#2E4A62"
        }
    }
}

A gradient

A gradient goes from the first color of its stops, at the top, to the last, at the bottom. Without the front image.

{
    "front": {
        "background": {
            "gradient": {"stops": ["#1E3A8A", "#93C5FD"]}
        }
    }
}

An angled gradient

Its angle is given in degrees, as in CSS: 0 goes upwards, 90 to the right, 180 (the default) downwards, 270 to the left.

{
    "back": {
        "background": {
            "gradient": {"angle": 45, "stops": ["#FDE68A", "#F97316"]}
        }
    }
}

A radial gradient

type: radial goes from the center of the part, in the first color, to its corners, in the last. Without the front image.

{
    "front": {
        "background": {
            "gradient": {"type": "radial", "stops": ["#FFFFFF", "#7EA117"]}
        }
    }
}

A translucent gradient over a color

The gradient fades from transparent to dark over the color: the layers add up. Without the front image.

{
    "front": {
        "background": {
            "color": "#C2410C",
            "gradient": {"stops": ["#00000000", "#000000CC"]}
        }
    }
}

An image across the spine

front.background.image-starts-in-spine starts the front image at the spine; back.background.image-expands-into-spine extends the back image over it.

{
    "front": {
        "background": {
            "image": "photo.png",
            "image-starts-in-spine": true
        }
    }
}

The margin box of the back

back.margin-box is a band along the left edge of the back, with a shadow on its right. It takes a background like the parts.

{
    "back": {
        "margin-box": {
            "gradient": {"stops": ["#7EA117", "#1F3A0B"]}
        }
    }
}

Text: font, size, color and case

Every text of the cover has the same properties: back.title, back.subtitle, back.volume, back.volume-title, spine.author, spine.title, front.author, front.title, front.subtitle, front.volume, front.volume-title and front.epigraph. Its font sets the family, the size, the style and the case of the letters, and its fill their color. A text shrinks until it fits its area: its font.size is the largest size it takes.

Font, size and color

font.family is a font family of the fonts folder.

{
    "front": {
        "title": {
            "font": {"family": "Myriad Pro", "size": "44pt"},
            "fill": "#B45309"
        }
    }
}

Bold and italic

font.style is None, Bold, Italic or Bold-Italic.

{
    "front": {
        "author": {
            "font": {"style": "Bold"}
        },
        "title": {
            "font": {"style": "None"}
        }
    }
}

Capitals

font.case is None, UpperCase, TitleCase (a capital at the start of each word) or SmallCaps.

{
    "front": {
        "author": {
            "font": {"case": "SmallCaps"}
        },
        "title": {
            "font": {"case": "UpperCase"}
        }
    }
}

Translucent text

Two more digits in the fill color make the text translucent.

{
    "front": {
        "title": {
            "fill": "#54751680"
        }
    }
}

Text effects

Borders, gradients, images and bands work on every text but the back content. A fill is a color or a gradient; an image replaces it. A border has a fill too.

A border

border takes a fill and a width, 1.25pt by default.

{
    "front": {
        "title": {
            "border": {"fill": "#1F2937", "width": "1pt"}
        }
    }
}

Outline only

A fully transparent fill (00) with a border leaves the outline.

{
    "front": {
        "title": {
            "fill": "#FFFFFF00",
            "border": {"fill": "#547516", "width": "1.5pt"}
        }
    }
}

A gradient

A gradient fill lists its colors in stops, from the first to the last, with an angle in degrees, as a background gradient: here from left (90) to right.

{
    "front": {
        "title": {
            "fill": {"angle": 90, "stops": ["#C0392B", "#2E86C1"]}
        }
    }
}

A gradient with more colors

More stops add colors between the first and the last. A position, from 0 to 100, can follow a color: #F1C40F 50; colors without one are spread evenly.

{
    "front": {
        "title": {
            "fill": {"stops": ["#C0392B", "#F1C40F 50", "#2E86C1"]}
        }
    }
}

A radial gradient

type: radial goes from the center of the text to its corners.

{
    "front": {
        "title": {
            "fill": {"type": "radial", "stops": ["#F1C40F", "#B91C1C"]}
        }
    }
}

A gradient border

A gradient border.fill takes the same values as a text gradient.

{
    "front": {
        "title": {
            "fill": "#FFFFFF",
            "border": {"fill": {"angle": 90, "stops": ["#7C3AED", "#DB2777"]}, "width": "2pt"}
        }
    }
}

An image in the text

image fills the letters with an image of the cover’s folder.

{
    "front": {
        "title": {
            "image": "text-texture.png"
        }
    }
}

A background band

band draws a band under the text: its color, its padding (1mm by default) and its radius, for rounded corners. Without the front image.

{
    "front": {
        "background": {
            "color": "#2E4A62"
        },
        "author": {
            "band": {"color": "#FFFFFFCC", "padding": "2mm", "radius": "2mm"}
        }
    }
}

One gradient for the title block

With extent: block, the title shares its gradient, image and band with its subtitle and volume.

{
    "front": {
        "title": {
            "fill": {"stops": ["#C0392B", "#2E86C1"]},
            "extent": "block"
        }
    }
}

Rotation

rotation turns the author, title or epigraph clockwise, in degrees: -8 tilts it upwards.

{
    "front": {
        "title": {
            "rotation": -8
        }
    }
}

Subtitle, volume and volume title

The subtitle, volume and volume title follow the title, below it. They take the title’s font, fill, image and border unless they set their own; their size is smaller than the title’s unless they set it. hidden hides them: back.hidden, spine.hidden and front.hidden take subtitle, volume and volume-title, true to hide.

Showing the volume

The front hides the volume by default: front.hidden.volume: false shows it.

{
    "front": {
        "hidden": {
            "volume": false
        },
        "subtitle": {
            "fill": "#B45309"
        },
        "volume": {
            "font": {"size": "20pt"}
        }
    }
}

Back cover

The back shows the title, the back text of the book and its thumbnail, then the publisher, price and barcode at the bottom.

The title on the back

back.title.inline writes it on one line, back.hidden.title removes it.

{
    "back": {
        "title": {
            "font": {"size": "24pt", "case": "UpperCase"},
            "fill": "#B45309"
        }
    }
}

The back text

back.content sets its font and fill. The text shrinks from this size until it fits.

{
    "back": {
        "content": {
            "font": {"size": "11pt"},
            "fill": "#1F3A0B"
        }
    }
}

The thumbnail

back.thumbnail is a small image in the text, framed with a shadow. top-line-skip moves it down by lines of text; width and hoffset (how far it reaches into the margin box) size and place it.

{
    "back": {
        "thumbnail": {
            "top-line-skip": 4,
            "width": "35mm",
            "hoffset": "20mm"
        }
    }
}

A thumbnail without a frame

With back.thumbnail.wrap: contour, the text follows the outline of an image with a transparent background.

{
    "back": {
        "thumbnail": {
            "image": "back-thumbnail.png",
            "wrap": "contour"
        }
    }
}

Spine

The spine shows the author at the top, the title in the middle and the publisher’s logo at the bottom. spine.hidden.title hides the title.

Spine text

The volume follows the title on the spine.

{
    "spine": {
        "background": {
            "color": "#1F2937"
        },
        "title": {
            "font": {"case": "UpperCase"},
            "fill": "#FDE68A"
        }
    }
}

Front cover

The front stacks three sections: by default the author (upper), the title (middle) and the epigraph (lower). A box places a text at exact coordinates instead.

A larger title section

front.section-layout: big-title gives the title three quarters of the height, the epigraph one quarter.

{
    "front": {
        "section-layout": "big-title"
    },
    "settings": {
        "debug-boxes": true
    }
}

Moving the author down

section sets the section of front.author, front.title or front.epigraph, with its alignment. Two texts cannot share a section.

{
    "front": {
        "author": {
            "section": {"name": "lower", "valign": "bottom", "halign": "center"}
        },
        "title": {
            "section": {"name": "upper", "valign": "top", "halign": "center"}
        }
    }
}

A text at exact coordinates

box places the text in a rectangle measured from the top left corner of the front, on a 14 × 21 cm cover.

{
    "front": {
        "title": {
            "box": {"top": "120mm", "left": "15mm", "bottom": "170mm", "right": "90mm", "valign": "center", "halign": "left"}
        }
    },
    "settings": {
        "debug-boxes": true
    }
}

The epigraph

A quotation under the title, shown with front.hidden.epigraph: false. Without the front image.

{
    "front": {
        "background": {
            "color": "#F4EFE1"
        },
        "hidden": {
            "epigraph": false
        },
        "epigraph": {
            "font": {"family": "Myriad Pro", "size": "13pt", "style": "Italic"},
            "fill": "#547516"
        }
    }
}

Fonts

Every font family a cover uses has a folder of the same name in the Nextcloud folder Book covers/_fonts, such as Book covers/_fonts/Myriad Pro. Pick a family from there, and write its folder name exactly in the font.family properties. A family without a folder stops the generation of the cover.

Adding a font

  1. Create a folder named after the family in Book covers/_fonts.
  2. Put the font files in it: .ttf or .otf, one per style. The regular style is required; bold, italic and bold italic are used for Bold, Italic and Bold-Italic text.
  3. Add a fontconfig.json file, which names the family and its file for each style:
{
    "family": "Myriad Pro",
    "files": {
        "Regular": "MyriadPro-Regular.ttf",
        "Bold": "MyriadPro-Bold.ttf",
        "Italic": "MyriadPro-Italic.ttf",
        "BoldItalic": "MyriadPro-BoldItalic.ttf"
    }
}

Languages

One cover serves every language of a book. settings.languages changes some properties for a language, such as a font size or a box; settings.font-substitutions replaces the fonts that lack the letters of a language, such as Russian letters in a font made for French. A replacement font needs its folder in _fonts too, unless it is installed with docpross.

{
    "front": {
        "title": {
            "font": {"size": "60pt"}
        }
    },
    "settings": {
        "languages": {
            "am": {
                "front": {
                    "title": {
                        "font": {"size": "40pt"}
                    }
                }
            }
        },
        "font-substitutions": {
            "ru": {
                "*": "Noto Sans",
                "Abadi MT": "Noto Sans Light"
            }
        }
    }
}
